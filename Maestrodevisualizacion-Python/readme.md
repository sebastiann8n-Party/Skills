# Maestro de Visualización - Python 📊🚀

Un espacio diseñado para pasar de simplemente "hacer gráficos" a **dominar las habilidades de visualización de datos** en Python. Este repositorio va más allá de lanzar líneas de código: busca estructurar el aprendizaje de forma estratégica para entender el verdadero valor analítico y visual de cada gráfico.

## 🎯 Objetivo y Metodología

Este proyecto se aleja de los típicos scripts aislados y adopta una metodología de estudio estructurada alrededor de archivos **`skill.md`**. Por cada gráfico o técnica de visualización, encontrarás un desglose basado en tres pilares:

1. **Buenas prácticas:** Reglas de oro de diseño visual para que el gráfico sea legible y comunique correctamente.
2. **Implementación técnica:** Código limpio, documentado y listo para replicar usando bibliotecas como Matplotlib y Seaborn.
3. **Criterio analítico:** El "porqué" detrás de cada decisión visual y en qué contexto aporta valor real.

## 🚀 ¿Cómo usar este material?

Te recomiendo que no solo copies y pegues el código. Entra en la carpeta de cada nivel y lee primero el archivo `skill.md` correspondiente. Ese documento te dará el contexto técnico y teórico necesario para entender por qué construimos el gráfico de esa manera y cómo evitar los errores más comunes de diseño.
